# Vaccination Data Analysis

A data analysis project focused on exploring vaccination records and presenting useful insights through SQL and Power BI.

The main goal of this project is to organize vaccination data, analyze important trends, and present the results through interactive dashboards that are easy to understand.

---

## 📌 About the Project

Vaccination programs generate a large amount of data related to people, vaccination status, vaccine types, locations, and other healthcare information.

In this project, I worked with vaccination-related data and used **SQL** for data management and analysis and **Power BI** for visualization.

The project helped me understand how raw data can be transformed into meaningful information that can be used for analysis and reporting.

---

## 🎯 Project Objectives

- Store and organize vaccination-related data efficiently.
- Use SQL to retrieve and analyze relevant information.
- Identify useful patterns and trends in the dataset.
- Create interactive dashboards using Power BI.
- Present important vaccination statistics in an easy-to-understand format.

---

## 🛠️ Technologies Used

- **SQL** – Data storage, querying and analysis
- **Power BI** – Data visualization and dashboard creation
- **Excel/CSV** – Data preparation and handling
- **GitHub** – Project documentation and version control
